# できたのかけら ステップ配信

「できたのかけら診断」PDFの友だち登録から、9月9日開催「できたのかけらワークショップ」への
参加申込みまでをつなぐ、LINE公式アカウントのステップ配信シナリオ・文面。

## 内容

- `step-messages.md` — 配信スケジュールと全5通の文面（コピペしてLINE公式アカウントマネージャーに登録する用）

## 構成

登録直後〜3〜4日間で計5通を配信する短期集中型。

1. PDFお届け（即時）
2. 診断内容への共感を深める（+1日）
3. ワークショップの存在を予告（+2日）
4. 日時・特典・定員などの詳細とCTA（+3日）
5. 定員・締切の後押し（+3〜4日、最終）

## 設定について

このリポジトリには配信文面のみを用意している。実際の配信設定
（LINE公式アカウントマネージャーの「ステップ配信」機能でのシナリオ登録、
トリガー設定、送信タイミング設定）は管理画面上で別途行う必要がある。

設定時は以下を確認する。

- トリガー：診断PDF配布時の友だち追加（またはリッチメニュー等でのPDF請求アクション）
- 各配信の送信タイミング：友だち追加日時起点で `step-messages.md` のスケジュール表のとおりに設定
- `[診断PDFのURL]` `[LPのURL]` の差し込み：配布用URLに置き換え
- ワークショップ開催日（9/9）直前に登録した友だちへの配信④・⑤の間隔調整
